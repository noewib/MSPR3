1 Sources de données

Ce service de prédiction s'appuie sur les données ouvertes publiées par RTE (Réseau de Transport d'Électricité) via la plateforme eCO2mix :

🔌 RTE eCO2mix

Données de production et de consommation électrique en temps réel pour la France métropolitaine.

🌐 Lien : https://www.rte-france.com/eco2mix

  • Ouverture — ne pas appliquer de restrictions technologiques empêchant l'accès aux données.

Le modèle de prédiction est entraîné et évalué sur les jeux de données suivants :

Fichier Période Granularité Variables principales
eCO2mix Annuel Définitif 2020 — 2024 Demi-horaire (30 min) Consommation, production par filière, échanges, taux CO₂

4 Méthodologie de traitement

Les données brutes subissent les transformations suivantes avant l'entraînement du modèle :

  1. Agrégation temporelle

    Les données demi-horaires (48 points/jour) sont agrégées en moyennes journalières pour obtenir une granularité quotidienne.

  2. Feature engineering
    • Lags temporels — consommation à J-1, J-7 et J-14 pour capturer les tendances et saisonnalités.
    • Moyennes glissantes — moyennes sur 7 et 30 jours pour lisser les variations court-terme.
    • Variables calendaires — jour de la semaine, mois, indicateur week-end/jour férié pour modéliser les cycles hebdomadaires et saisonniers.
  3. Normalisation

    Application d'un StandardScaler (centrage-réduction) sur toutes les variables numériques pour garantir la convergence et la stabilité des algorithmes.

5 Accès API public

Les prédictions sont accessibles via l'API REST à l'endpoint suivant :

POST /predict

Exemple de requête

curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "date": "2025-06-15",
    "forecast_j_1": 52000.0,
    "forecast_j": 51500.0,
    "lag_1d": 53000.0,
    "lag_7d": 54000.0,
    "lag_14d": 52500.0,
    "rolling_mean_7d": 53200.0,
    "rolling_mean_30d": 54100.0,
    "fioul": 200.0,
    "coal": 0.0,
    "gas": 5000.0,
    "nuclear": 32000.0,
    "wind": 8000.0,
    "solar": 6000.0,
    "hydraulic": 9000.0,
    "pumping": -1500.0,
    "bioenergy": 800.0,
    "physical_exchanges": -3000.0,
    "co2_rate": 45.0
  }'

Format de réponse

{
    "date": "2025-06-15",
    "prediction_mw": 51842.37,
    "status": "success",
    "model_used": "GradientBoostingRegressor",
    "latency_sec": 0.003421
}

Codes de réponse

Code Signification
200Prédiction réussie
400Requête invalide (paramètres manquants ou incorrects)
422Erreur de validation des données d'entrée
500Erreur interne du serveur
503Modèle non chargé / Service indisponible

6 Réutilisation

Les prédictions générées par le Service sont accessibles librement et peuvent être réutilisées sous les conditions suivantes :

  • Attribution requise — toute réutilisation des résultats doit inclure la mention :

« Données source : RTE eCO2mix — Prédictions : EDF R&D Electricity Consumption Predictor »

  • Les données sources RTE eCO2mix restent soumises à la licence ODbL.
  • Les prédictions du modèle ne sont pas garanties et sont fournies « en l'état » (as is).
  • Toute réutilisation à des fins critiques (sûreté du réseau, trading énergie) doit faire l'objet d'une validation indépendante.
